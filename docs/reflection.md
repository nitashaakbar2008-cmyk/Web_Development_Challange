# Project reflection

Building AURELLE & CO. was an exercise in balancing an expressive editorial mood with practical shopping cues. I focused on a calm palette, generous spacing, and clear product information so the interface could feel premium without hiding useful actions. Keeping the experience in plain HTML, CSS, and JavaScript made the project easy to run and helped keep the interactions understandable. The bag and wishlist demonstrate persistence while staying honest that no order or payment is real. I also made space for accessibility details such as semantic sections, labeled fields, keyboard focus, and reduced-motion preferences. The image-led design depends on external services, so local assets and real browser testing would be valuable next steps. I would personalize this reflection with what I learned, which parts felt strongest, and what I would improve after testing on my own devices.
