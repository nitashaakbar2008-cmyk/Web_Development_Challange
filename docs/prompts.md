# Useful project prompts

These prompts are distinct starting points for continuing or adapting the project.

## 1. Planning and documentation
**Prompt:** “Plan a lightweight, static premium fashion storefront called AURELLE & CO. Define the audience, site goals, page sections, delivery phases, file structure, and a concise documentation set. Clearly identify which business services are out of scope.”

**Purpose:** Turn the brief into an actionable, bounded project plan.  
**Expected outcome:** A prioritized section/feature list, simple architecture, and submission-ready documentation outline.

## 2. UI/UX and visual implementation
**Prompt:** “Design and implement an editorial, responsive landing page for AURELLE & CO. Use warm ivory, cream, champagne, blush, sage, and charcoal; pair an elegant serif with a readable sans serif. Include image-led category cards, a product grid, a collection feature, accessible navigation, and restrained hover states. Use semantic HTML and plain CSS.”

**Purpose:** Guide the visual system and complete page composition.  
**Expected outcome:** A polished layout with a consistent type/color scale, responsive breakpoints, and accessible controls.

## 3. Functionality, responsiveness, and testing
**Prompt:** “Using vanilla JavaScript, add searchable/filterable sample products, a removable bag and wishlist persisted in localStorage, a mobile menu, FAQ disclosures, and client-side contact/newsletter validation. Do not send data or implement checkout. Test desktop, tablet, and mobile behavior, keyboard focus, empty search, persistence, and invalid form input; document only tests actually performed.”

**Purpose:** Specify interaction behavior and responsible verification.  
**Expected outcome:** Working frontend-only interactions, explicit demo limitations, and an honest test record.
