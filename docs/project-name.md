# Project name

**AURELLE & CO.**

**Tagline:** Thoughtful pieces for a life beautifully lived.

## Brand overview
AURELLE & CO. is a fictional premium fashion and lifestyle brand for a considered edit of clothing, jewelry, handbags, perfumes, watches, footwear, and accessories.

## Project description
This static e-commerce landing page concept introduces the brand and presents a small curated assortment through an editorial responsive interface. Its search, category filters, bag, and wishlist are frontend demonstrations only.
