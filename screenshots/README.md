## Capturing additional screenshots

No screenshots are supplied or claimed as captured. To create actual submission images:

1. Open `index.html` in a browser or run it with VS Code Live Server.
2. Set a desktop viewport (for example 1440 × 1000), capture the page, and save it as `screenshots/desktop.png`.
3. Set a mobile viewport (for example 390 × 844), capture and save as `screenshots/mobile.png`.
4. Review the saved images before linking them in the project README.

Use your browser's built-in screenshot feature or an OS capture utility. Include only screenshots you actually captured.
